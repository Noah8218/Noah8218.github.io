# docs/sources: 공개 README 스냅샷

이 폴더는 사용자가 GitHub에 공개한 저장소(`Noah8218/*`)의 README 와 저장소 메타 정보를 내려받아 둔 사본이다.
사이트(`index.html`)의 모든 영어 문장과 프로젝트 설명 한국어 문장은 여기 있는 문장에 근거한다.
`python tools/check_site.py` 가 이 폴더의 `README_*.md`, `stats.md`, `meta_*.json` 을 하나의 말뭉치로 묶어, 사이트의 보이는 문장이 그 안에 있는지 검사한다.
이 `README.md` 는 말뭉치에 들어가지 않는다.

- 스냅샷 날짜: 2026-11-27 (`stats.md` 의 조회일 기준. README 와 메타도 같은 날 내려받았다)
- 대상: 모두 `Noah8218` 소유의 공개 저장소 7개(OpenVisionLab, OpenVisionLab-Labeling-Studio, OpenVisionLab-3D-Studio, OpenVisionLab-Machine-Studio, OpenVisionLab-Vision-SDK, RawBufferVisualizer, 프로필 저장소 Noah8218)
- 저장 형식: BOM 없는 UTF-8, 줄 끝 LF. 내용은 받은 그대로이고, README 안의 상대 링크와 이미지 경로는 이 폴더에서 열리지 않는다(원본 저장소 기준 경로이기 때문)

## stats.md 의 의미

`stats.md` 는 GitHub API 로 조회한 값(별 수, 팔로워 수, 라이선스)과 프로필 소개를 2026-11-27 에 손으로 정리한 문서다. 자동으로 만들어지지 않는다.
사이트의 GitHub 별 수와 기준 날짜 같은 현황 문구의 근거이며, 위 말뭉치에 들어간다.

- 별 수: 각 `meta_*.json` 의 `stargazers_count`. 합계는 공개 프로젝트 6개의 합이고 프로필 저장소(별 0)는 포함하지 않는다.
- 라이선스: 각 저장소의 라이선스 표기. RawBufferVisualizer 는 API 의 `license.spdx_id` 가 `NOASSERTION` 이라, README 가 밝힌 MIT 를 따른다.
- 팔로워 수: `https://api.github.com/users/Noah8218` 응답의 `followers`. 저장소 메타(`meta_*.json`)에는 없다.

갱신 방법(`stats.md` 는 `tools/fetch_sources.py` 가 덮어쓰지 않는다):

1. `python tools/fetch_sources.py` 로 `meta_*.json` 을 새로 받는다.
2. `meta_*.json` 의 `stargazers_count` 를 저장소별로 읽고 합계를 다시 계산해 `stats.md` 의 별 수 줄을 고친다. 라이선스는 `license.spdx_id` 와 README 를 본다.
3. 팔로워 수는 `https://api.github.com/users/Noah8218` 의 `followers` 값으로 고친다(브라우저나 curl 로 조회).
4. `stats.md` 첫 줄의 조회일과 이 문서의 "스냅샷 날짜"를 오늘 날짜로 고친다.
5. 사이트의 별 수·기준 날짜 문구도 같이 고치고 `python tools/check_site.py` 를 다시 돌린다.

## 다시 받는 법

```
python tools/fetch_sources.py --dry-run   # 받을 주소만 출력(요청하지 않음)
python tools/fetch_sources.py             # 받아서 이 폴더의 파일을 덮어씀
```

- 토큰 없이 공개 API 를 쓰며, GitHub API 는 비인증 요청이 시간당 60회로 제한된다. 이 스크립트는 한 번에 API 요청 14회를 쓴다.
- 받지 못한 파일이 하나라도 있으면 아무것도 덮어쓰지 않는다.
- 덮어쓰기 전에 작업 내용을 커밋해 두고, 받은 뒤 `git diff docs/sources` 로 무엇이 바뀌었는지 본다.

## 주의

- 사본은 2026-11-27 시점의 것이다. 원본 README, 별 수, 릴리스 버전은 그 뒤 바뀌었을 수 있다. 사이트 문구를 고치기 전에 새로 받아 비교한다.
- 사이트 문장을 새로 쓸 때는 이 폴더에 근거가 있는 문장만 쓰고, 번역·편집한 문장은 사이트의 수정 문구 표시 규칙(`tools/README.md`)을 따라 표시한다.
- 이 폴더의 파일은 직접 고치지 않는다. 고치려면 원본 저장소의 README 를 고친 뒤 다시 받는다(`stats.md` 만 예외).
