# 배경과 결정 기록

이 사이트가 왜 지금 모습인지, 사용자(저장소 주인)가 무엇을 말하고 무엇을 정했는지를 시간순으로 남긴다. 작업 전에 "이미 정해진 것"과 "아직 정해지지 않은 것"을 구분하는 용도다.

- **사실의 종류를 구분한다.** `사용자 발언`은 사용자가 대화에서 한 말이고, `AI 판단`은 작업자(AI)가 정한 것이며, `미확인`은 확인하지 못한 것이다. 사용자 발언은 대화에서 가져온 문장이라 원문이 이 저장소에 따로 없다.
- **날짜.** 대부분의 단계는 날짜를 기록하지 않았다. 알 수 있는 날짜는 작업일인 **2026-11-27**(GitHub 수치 조회일, 이 문서 작성일)뿐이라 순서만 적는다.

## 2. 폐기한 방향: 슬라이드 덱

- **무엇이었나.** 사용자의 "HTML 발표자료" 요청을 16:9 슬라이드 덱으로 만든 것.
- **왜 폐기했나.** 사용자가 의도한 것은 발표자료가 아니라 nazmussayad.com 같은 스크롤형 개인 사이트였다. 용어("HTML 발표자료")와 의도가 달랐다.
- **교훈.** 요청 문구와 레퍼런스가 어긋나면 만들기 전에 한 번 확인한다. 이 사이트에 슬라이드 방식을 다시 들이지 않는다.

- 라이트 기본 + 다크 토글, 히어로 이름 축소 상태다. 버그 수정 7건은 다른 작업자가 진행했고, 이 문서를 쓰는 동안 코드에 반영되는 것을 봤지만 **완료 기준으로 검증하지 않았다**(상세는 [03-site-architecture.md](03-site-architecture.md) 8절). `git log`(저장소가 git으로 올라간 뒤)와 코드로 확인한다.
- 이 평가·보고서들은 다크 기본·큰 이름 시점의 사이트를 본 것이라, 줄 번호와 일부 관찰이 지금과 다르다.
- 점수는 모두 AI 평가자의 것이며 사람의 의견이 아니다.
